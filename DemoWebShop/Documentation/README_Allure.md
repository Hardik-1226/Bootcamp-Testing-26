# Allure Reports - DemoWebShop Automation Framework

## Overview

Allure is integrated into every test class with the following annotations:

| Annotation    | Purpose                          | Example                     |
|---------------|----------------------------------|-----------------------------|
| `@Epic`       | Top-level grouping               | `"DemoWebShop Automation"`  |
| `@Feature`    | Feature area                     | `"Login"`, `"Cart"`         |
| `@Story`      | Specific test story              | `"Valid Login"`             |
| `@Severity`   | Priority level                   | `BLOCKER`, `CRITICAL`       |
| `@Description`| Test description                 | `"Verify user can login"`   |

## Automatic Attachments

On test **failure**, the framework automatically attaches:
- ✅ Screenshot (PNG image)
- ✅ Log messages
- ✅ Browser information

This is handled in `BaseClass.java` → `@AfterMethod tearDown()`.

## Prerequisites

### Install Allure Command Line

**Windows (using Scoop):**
```bash
scoop install allure
```

**Windows (using Chocolatey):**
```bash
choco install allure
```

**Mac:**
```bash
brew install allure
```

**Verify installation:**
```bash
allure --version
```

## How to Generate Reports

### Step 1: Run Tests

```bash
mvn clean test
```

This generates results in `allure-results/` folder.

### Step 2: Serve Report (Opens in Browser)

```bash
allure serve allure-results
```

This starts a local server and opens the report in your browser.

### Step 3: Generate Static Report

```bash
allure generate allure-results --clean -o allure-report
```

Then open `allure-report/index.html` in any browser.

---

## Report Sections

| Section       | What it Shows                              |
|---------------|--------------------------------------------|
| Overview      | Pass/fail summary, severity distribution   |
| Suites        | Tests grouped by class                     |
| Graphs        | Charts for status, duration, trends        |
| Timeline      | Test execution timeline                    |
| Behaviors     | Tests grouped by Epic → Feature → Story    |
| Packages      | Tests grouped by Java package              |

## Maven Plugin Commands

```bash
# Generate report using Maven plugin
mvn allure:report

# Serve report using Maven plugin
mvn allure:serve
```

## Folder Structure

```
allure-results/          ← Generated by tests (JSON files)
allure-report/           ← Generated by allure generate command
  ├── index.html         ← Open this in browser
  ├── data/
  ├── export/
  ├── history/
  └── widgets/
```

---

## Tips

1. **Always run `mvn clean test`** before generating reports
2. **Delete `allure-results/`** before each fresh run to avoid stale data
3. Use **`allure serve`** for quick viewing (auto-opens browser)
4. Use **`allure generate`** to create a shareable HTML report
